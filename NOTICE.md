# Open-source provenance

This repository integrates small, task-relevant parts of RoboMaster projects.

1. `src/sentry_motion_manager/` is copied from [Boombroke/Sentry26](https://github.com/Boombroke/Sentry26), commit `9f3ae17627cef5ca1f102a27668f8b5e78a2cdb1`. Its source files and `package.xml` identify Apache-2.0 and retain the original copyright notices. This repository configures it for a 0.22 m differential robot and passes its stamped output to Gazebo through `community_demo/cmd_bridge.py`; the original Livox, terrain, RM referee and serial modules are not included.
2. `src/community_demo/community_demo/bounded_pid.py` is a reduced Python adaptation of the bounded PID in [SMBU PolarBear's `pb_omni_pid_pursuit_controller`](https://github.com/SMBU-PolarBear-Robotics-Team/pb_omni_pid_pursuit_controller), commit `6f0ef65f52b65aef0bf0350926947f7813c5b568`, `src/pid.cpp`, copyright 2025 Lihan Chen, Apache-2.0. The full omnidirectional Nav2 plugin is inappropriate for this small differential chassis; this adaptation keeps only bounded translation and heading control.

3. `src/community_demo/gui/overview.config` adapts the plugin layout of Gazebo Sim 8.15.0's installed `gui/gui.config` (Open Source Robotics Foundation and Gazebo contributors, Apache-2.0) to a compact overview without editor side panels. The physical-pose publisher is Gazebo's built-in [OdometryPublisher](https://gazebosim.org/api/sim/8/classgz_1_1sim_1_1systems_1_1OdometryPublisher.html).

The generated world, route state machine, ROS bridge adapter, traffic-light colour baseline, physical-lap verifier and documentation are new code for this project. The repository root `LICENSE` contains Apache-2.0. No code or assets from `Gh0stown/AiC-2026` are used.

## User-supplied semifinal assets (2026-10-01)

`src/community_demo/models/community_assets/materials/textures/` contains 27 valid images copied byte-for-byte from the user's AIC semifinal ZIP. The importer records source names, SHA-256 and metric dimensions in `manifest.json`. These supplied images are not covered by this repository's code license; their rights remain with their respective holders, and no additional asset license is claimed here. Do not publish them outside the authorized project without checking their applicable rights.

The incomplete car-background and yellow-off downloads could not be decoded. The world explicitly uses generated car-front geometry and a dark amber circle as temporary substitutes. Collada meshes are generated by this project's asset importer. Person height, cardboard thickness and inferred layout positions are documented assumptions, not official measurements.

## Vision dependencies and model provenance

- GPU detector: Ultralytics 8.4.164 / YOLO11n, upstream official `ultralytics/assets` release v8.4.0 pretraining weights. The fine-tuned `models/perception/best.pt` is trained from Gazebo camera frames of the user-supplied standees. Ultralytics uses AGPL-3.0; see `licenses/Ultralytics-AGPL-3.0.txt`. The project code license does not replace that dependency/model license.
- OCR: RapidOCR 3.9.2, Apache-2.0, see `licenses/RapidOCR-Apache-2.0.txt`. Its downloaded PP-OCRv6 detector/recognizer and PP-OCRv2 angle model originate from PaddleOCR/RapidAI's configured official model distribution. These are pretrained OCR models, not models trained by this project.
- Chinese overlays: unmodified WenQuanYi Zen Hei font, GPL v2 with font embedding exception, retained in `models/fonts/FONTEXCEPTION`. Font source: https://wenq.org/wqy2/ . The exception applies to rendered output; the font itself retains its license.
- Nav2 and SLAM Toolbox are installed ROS dependencies. This project's launch/configuration uses them through ROS interfaces; their source is not copied into this repository.

Automatic geometric annotation is confined to offline dataset collection. Runtime perception does not import scene geometry or simulated identities. The independent result verifier contains transcribed plate references solely to score OCR results, never to fill runtime answers.
